OpenCloset 채팅 직접 테스트

서로 다른 두 사용자로 실제 로그인하고 WebSocket으로 대화합니다.

준비 버튼을 누르면 로컬 DB에 테스트 계정 2개·상품 1개·채팅방 1개를 생성합니다. 실제 계정은 사용하지 않습니다.

IntelliJ에서 앱을 실행했다면 주소를 http://localhost:8080으로 바꾸세요. 로컬 주소만 허용합니다.

먼저 백엔드와 DB·Redis를 실행하고 테스트를 준비하세요.

직접 확인할 순서

    
    
      
  1. 두 창이 연결됨이면 한쪽에서 메시지를 보내세요. 양쪽에 같은 메시지가 한 번씩 표시되어야 합니다.
    2. 
      
  2. 받은 쪽에서 안 읽은 수를 누르면 1 이상입니다. 읽음 처리 후에는 0이 됩니다.
    3. 
      
  3. 보낸 쪽에서 대화 불러오기를 누르면 읽음 여부도 갱신됩니다. 읽음 알림을 실시간으로 푸시하는 방식은 아닙니다.
    4. 
      
  4. 연결 끊기 → 연결하기 → 대화 불러오기로 이전 대화가 남아 있는지 확인하세요.
    5. 
      
  5. 빈 메시지 또는 1000자를 넘는 메시지를 보내면 오류가 표시되고 저장되지 않아야 합니다.
    6. 
    

    
JWT는 페이지 메모리에만 보관합니다. 새로고침하면 접속 정보가 사라집니다. 생성한 테스트 데이터는 로컬 DB에 남으며, 이 파일은 운영 JAR에 포함되지 않습니다.
